## About me

I'm Linh ᨳ𐔌՞҂ ˕ ֊՞𐦯ᜊ, a Computer Science student at Toronto Metropolitan University, based in Toronto. For a long time, I wasn’t sure what I was passionate about. That slowly changed as I explored technology and spent more time building my own projects, from small experiments to more involved ones. Somewhere between getting stuck, figuring things out, and finally making something work, I realized how much I enjoy creating things with computers.

What excites me most is having a way to turn my imagination into something other people can see, use, or interact with. I want to bring creativity into the technical work I do and build things that combine human ideas with what machines can do. That could mean creating a world someone can explore, giving a character a sense of life, or teaching a computer to make sense of an image.

I'm especially interested in game development, 3D graphics, and computer vision, and I'm currently exploring machine learning and AI. I’m still figuring out where these interests will take me, but I’ve found something I want to keep coming back to: starting with an idea I don’t quite know how to build yet, then learning enough to make it real.

## Projects

### [Sentinel](https://github.com/linguyn/sentinel)

An AI-assisted game testing platform in development, designed to automate gameplay checks and help developers find unexpected behavior. Combines a Unity game client with a Python backend, with the goal of turning test runs into useful bug reports and reducing repetitive manual testing.

- **Languages:** Python, C#
- **Technologies:** Unity 6, Universal Render Pipeline (URP), FastAPI, Pydantic, Uvicorn, UnityWebRequest, HTTP/JSON
- **Planned:** Rule-based and AI test agents, test logging and database storage, automated bug detection, AI-assisted bug analysis and reporting

### [Co-op Management App](https://github.com/linguyn/406coopapp)

A web application that helps students, supervisors, and coordinators manage university co-op placements. Brings applications, approval tracking, progress reports, student reflections, and coordinator dashboards into one place.

- **Languages:** JavaScript, HTML, CSS
- **Technologies:** React, Node.js, Express.js, MongoDB, Mongoose, React Router, Axios, Chart.js, Vite, JWT authentication, bcrypt.js, Swagger/OpenAPI

### [Climate Awareness](https://github.com/linguyn/climate-awareness)

A team-built web application that helps people understand their environmental impact through a carbon footprint questionnaire, educational content, and practical suggestions for sustainable habits. Also includes a chatbot interface for asking questions.

- **Languages:** JavaScript, Ruby, HTML, CSS
- **Technologies:** React, React Router, styled-components, Axios, Ruby on Rails
- **Additional dependencies:** OpenAI SDK, Express.js, Redux, Yup
